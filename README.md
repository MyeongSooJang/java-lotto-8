# 로또

## 기능 구현 목록

### 도메인

#### Lotto (로또 한 장)
- [ ] 6개의 번호로 생성된다.
- [ ] 6개가 아니면 예외가 발생한다.
- [ ] 중복된 번호가 존재하는지 확인한다.
- [ ] 다른 번호 목록과 일치하는 개수를 반환한다
- [ ] 특정 번호를 포함하는지 확인한다

#### LottoBundle (로또 다발)
- [ ] 구매한 로또들로 생성이 된다.
- [ ] 당첨 번호와 비교하여 로또 결과를 반환한다.
- [ ] 구매한 로또 개수를 반환한다.

#### Rank (순위)
- [ ] 각 등수의 상금을 반환한다.
- [ ] 일치 개수와 보너스 일치 개수로 등수를 판단한다.
- [ ] 3개 미만인 경우 Fail 을 반환한다.

#### WinningNumbers (당첨 번호)
- [ ] 당첨 번호 6개로 생성이 된다.
- [ ] 로또를 넣으면 일치하는 갯수를 반환한다.
- [ ] 각 번호가 1~45 범위인지 검증한다.

#### BonusNumber (보너스 번호)
- [ ] 보너스 번호 1개로 생성이 된다.
- [ ] 당첨 번호와 중복인지 확인한다.

#### PurchaseAmount (구매 금액)
- [ ] 구매 금액으로 생성이된다.
- [ ] 1000원 단위가 아닌 경우 예외를 발생시킨다.
- [ ] 0 또는 음수를 입력하는 경우 예외를 발생시킨다.
- [ ] 구매 할 수 있는 로또 갯수를 반환한다.

#### LottoResult (로또 결과)
- [ ] 등수 별 당첨 갯수를 저장한다.
- [ ] 특정 등수의 갯수를 반환한다.
- [ ] 수익률을 계산한다.
- [ ] 총 상금을 계산한다.

### 입출력

#### InputView
- [ ] 구매 금액을 입력받는다
- [ ] 숫자가 아닌 값 입력 시 예외가 발생한다
- [ ] 당첨 번호를 입력받는다 (쉼표 구분)
- [ ] 당첨 번호 파싱 시 예외를 처리한다
- [ ] 보너스 번호를 입력받는다
- [ ] 예외 발생 시 에러 메시지 출력 후 재입력받는다

#### OutputView
- [ ] 구매한 로또 개수를 출력한다
- [ ] 발행된 로또 목록을 출력한다 (오름차순 정렬)
- [ ] 당첨 통계를 출력한다
- [ ] 수익률을 출력한다
